# Metro Vice RP — Bedrock Resource Pack

This pack is packaged as `.mcpack` for Geyser's `packs` directory. It includes the Bedrock item atlas and custom item textures for the EMS medical bag and police laptops, in addition to the phone/radio textures.

Geyser also needs the matching JSON mapping file at `plugins/Geyser-Spigot/custom_mappings/MetroViceRP.json`, and custom content must be enabled in Geyser's configuration. Restart Geyser/server after installing both files.

The plugin inventory menus provide the interactive game systems; this pack only supplies Bedrock-side visuals. Test with an actual Bedrock client after installation.
