# Metro Vice RP — Java Resource Pack

Target: Minecraft Java 26.3 (resource pack format 97.1).

This pack contains the Metro Vice RP visual foundation and item models for the EMS medical bag, police MDT laptop, and police rank-management laptop. The clock and goat horn textures are used for the in-game phone and radio devices.

The interactive screens are provided by the plugin's inventory interfaces. A resource pack supplies textures/models; it does not itself implement banking, messaging, character data, police records, or EMS logic.

The Java ZIP must be hosted at a direct HTTPS URL and its SHA-1 configured in the plugin's `resource-pack` section.
